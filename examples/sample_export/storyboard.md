# 版面文字說明 — MoviePy 小測驗（範例）

> 由 whitebox-video-storyboard 0.2.0 產生。本文件以**純文字**描述每個場景與元件的位置、大小、文字、時間與動畫，
> 讓 AI Agent 不必看草稿圖也能理解版面。精確數值以 `layout.json` 為準。

## 總覽

- 畫布：1920×1080 px（16:9，橫式），30 fps。
- 總長 14.00 秒，共 3 個場景，依序播放。
- 座標：原點在畫面左上角，x 向右、y 向下，單位為像素；元件的 (x, y) 是它的**左上角**，百分比是相對於畫面寬／高。
- 疊放：z 值越大越上層（後畫的蓋住先畫的）。
- 安全框：title-safe（內縮 10%）為 x 192–1728、y 108–972，重要文字應放在其中；action-safe（內縮 5%）為 x 96–1824、y 54–1026。
